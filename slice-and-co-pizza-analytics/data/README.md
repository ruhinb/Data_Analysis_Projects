# Data

| File | What it is |
|---|---|
| `data_pizza.csv` | 2015 point-of-sale transactions: 48,620 order lines, Windows-1252 encoding. Supplied with the project brief and imported into Power BI exactly as supplied. |
| `data_dictionary.xlsx` | Field descriptions for `data_pizza.csv`, as supplied. |
| `staffing_roster_2015.csv` | Staffing roster for the Workforce Efficiency page. One row per trading day × half-hour from 9:30 AM to 11:00 PM (10,024 rows): date, slot start, people on shift per role (shift managers, kitchen crew, service crew, prep/utility), total staff, paid labour hours and labour cost. |
